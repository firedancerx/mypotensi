# mypotensi1

Responsive 20-slide hero-carousel website for MyPotensi.

## Structure

- `index.html` — website shell
- `css/style.css` — responsive EmasPG-inspired visual system
- `js/carousel.js` — 20 slides and carousel interaction

## Interaction

- Left/right arrows
- Keyboard navigation
- Mobile swipe
- Hamburger navigation
- WhatsApp CTA to +60 11-6254 0028

## Copy
